데이터 기반 단계 정의 + 조건 검사 + UI 연출 전략 클래스를 조합해 런타임 튜토리얼 흐름을 안정적으로 제어한 구현입니다.

UniTask ScriptableObject Strategy Pattern SPA Dispatch

튜토리얼 시스템 개요

목표는 진행 조건을 만족한 튜토리얼 그룹만 자동 시작하고, 각 단계를 타입별 연출 로직으로 분기하여 사용자 입력을 안전하게 유도하는 것이었습니다.

핵심 설계는 데이터-제어-표현 분리입니다. 테이블 데이터(`TutorialData`, `TutorialGroupData`)로 단계를 선언하고, `TutorialManager`가 조건 검사를 통과한 그룹만 실행하며, `TutorialPanel` + Info 전략 클래스가 실제 UI/입력 유도를 담당합니다.

이 구조 덕분에 새로운 단계 타입 추가 시 `eTutorialType` 확장과 전용 Info 클래스 구현으로 영향 범위를 제한할 수 있습니다.
